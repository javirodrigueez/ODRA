Evaluate whether the patient's last utterance contains an explicit demand to change the current direction of the session.
The patient's last response is available as 'last_patient_response' within <session_context>, and you also have the recent exchange in <last_utterances>.

Return a JSON object with:
- "has_demand": true or false
- "demand_kind": "none", "end_session", "item_move", or "other"
- "demand": the patient's request written as a concise explicit demand, or null when there is no demand
- "reasoning": a brief explanation

Use these classes:
- "end_session": the patient explicitly wants to stop, leave, end, or not continue the session now
- "item_move": the patient explicitly wants to move on from the current topic, skip the current exercise, or change the immediate focus, but not end the whole session
- "other": the patient explicitly asks for a different kind of help, format, or therapist action that is not just ending the session or moving to the next item
- "none": no explicit demand is present

Be conservative:
- only explicit requests count as demands
- vague frustration, discouragement, skepticism, or discomfort without a clear request must return "has_demand": false and "demand_kind": "none"
- if "has_demand" is true, "demand" must quote or faithfully paraphrase the explicit request

Respond JSON: {{"has_demand": false, "demand_kind": "none", "demand": null, "reasoning": "..."}}

## Examples
Example 1:
Input: "I want to stop for today. I just need to go home."
Output:
{{
  "has_demand": true,
  "demand_kind": "end_session",
  "demand": "Stop the session for today and go home.",
  "reasoning": "The patient explicitly says they want to stop for today and go home, which is a direct request to end the session."
}}

Example 2:
Input: "Can we move on? I really don't want to keep talking about my childhood."
Output:
{{
  "has_demand": true,
  "demand_kind": "item_move",
  "demand": "Move on from talking about childhood.",
  "reasoning": "The patient explicitly asks to move on from the current topic without asking to end the full session."
}}

Example 3:
Input: "This feels useless. Just tell me how I can handle the situation."
Output:
{{
  "has_demand": true,
  "demand_kind": "other",
  "demand": "Give direct practical guidance on how to handle the situation.",
  "reasoning": "The patient explicitly asks for a different kind of therapist response, namely direct practical guidance, rather than simply ending the session or moving to the next item."
}}

Example 4:
Input: "I don't know if this is helping. Maybe I'm overreacting."
Output:
{{
  "has_demand": false,
  "demand_kind": "none",
  "demand": null,
  "reasoning": "The patient expresses doubt, but there is no explicit request to end the session, change focus, or do something different."
}}
